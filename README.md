<p align="center"><i>Follow the steps below to add this template to your Blogger blog.</i></p>

1. Download or clone the repo

   ```
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
   ```
  
2. Open your **Blogger Dashboard** and go to **Theme**

3. Click the arrow next to **Customize** and choose **Backup / Restore**

4. Click **Upload** and select the template `.xml` file from this repo

5. Open your blog in the browser and enjoy the new design 🎉
